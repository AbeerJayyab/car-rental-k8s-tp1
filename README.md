# Car Rental Microservice - Kubernetes & Docker

This repository contains the Spring Boot Car Rental Application deployed on Kubernetes (Minikube).

## Docker Registry (JFrog)
The Docker image for this application is built and hosted on **JFrog Artifactory**:
`trialbrpy4r.jfrog.io/car-rental-docker/car-rental-app:v1`

## Kubernetes Deployment
- **Deployment File:** `k8s/deployment.yaml`
- **Service File:** `k8s/service.yaml`
